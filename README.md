🎧 MP3 Tag Reader Using C

A CLI-based application developed in C to read and display MP3 metadata using the ID3v2 format.

🚀 Features
->Read MP3 metadata (Title, Artist, Album, Year, Genre, Comment)
->Supports ID3v2 tag parsing
->Efficient binary file handling
->Menu-driven / command-line interface

🧠 Concepts Used
->Structures
->File handling (binary mode)
->Pointers
->String manipulation
->CLI programming
